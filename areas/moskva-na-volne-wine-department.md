Часть кейса [[moskva-na-volne]].

- у «Москвы на волне» будет отдел российских вин с большим числом сортов
- концепция: QR-код → квиз из 3 вопросов (знание вин, повод, предпочтения) → простой ИИ рекомендует вина из каталога
- веб-страница из QR в браузере, брендированная «Москва на волне», а не Telegram Mini App; дизайн по брендбуку «Москвы на волне»
- собирать планируется вайбкодингом с Claude; демо на Netlify (бесплатно), потом российский VPS; домен на Рег.ру
- вина добавляются вручную через админку (описания из Excel, загрузка фото), без хардкода
- требования: без «позвать консультанта»; одно описание на вино; место как стеллаж + номер полки; в ответах квиза есть «Не знаю»; цены из 1С (карточка → Цены → «Прайс-лист компании»), только чтение
