Дополняет основной файл кейса [[moskva-na-volne]] (account-level).

- решения по сайту (ноябрь 2026): оффер «Свежая рыба как на прилавке»; доставка важнее офлайн-рынков; при заказе без выбора рынка (человек поправит в Купере/Яндекс Еде); писать «Доставка по всей Москве» (зону уточнят позже); название писать с тире «Москва — на волне»; в подвале «Городской проект»; минусы акции баллов не расписывать; корзина справа на десктопе — идеальное расположение, не трогать
- соцсети для подвала: Telegram t.me/mos_navolne и MAX max.ru/mos_navolne
- отложено на потом: цены на карточках, ассортимент (замороженное филе, больше SKU), зона доставки
- не писать на сайте «Привезёт Купер»; копирайтинг должен быть «вкусным», раз продаём рыбу
- обновления сайта выкладывать через его браузер (загрузка файлов в GitHub Drolkill/navolne), а не просить загружать вручную
