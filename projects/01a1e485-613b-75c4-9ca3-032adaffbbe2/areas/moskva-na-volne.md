Дополняет основной файл кейса [[moskva-na-volne]] (account-level).

- решения по сайту (ноябрь 2026): оффер «Свежая рыба как на прилавке»; доставка важнее офлайн-рынков; при заказе без выбора рынка (человек поправит в Купере/Яндекс Еде); писать «Доставка по всей Москве» (зону уточнят позже); название писать с тире «Москва — на волне»; в подвале «Городской проект»; минусы акции баллов не расписывать; корзина справа на десктопе — идеальное расположение, не трогать
- соцсети для подвала: Telegram t.me/mos_navolne и MAX max.ru/mos_navolne
- отложено на потом: цены на карточках, ассортимент (замороженное филе, больше SKU), зона доставки
- не писать на сайте «Привезёт Купер»; копирайтинг должен быть «вкусным», раз продаём рыбу
- обновления сайта выкладывать через его браузер (загрузка файлов в GitHub Drolkill/navolne), а не просить загружать вручную
- ноябрь 2026: сайт одобрен заказчиком, Фёдор переходит к полноценному воплощению (от макета к боевому сайту)
- архитектура боевого сайта: монолит на Go с чистым разделением по доменам, своя админ-панель, аналитика в Postgres, прод-деплой в Docker с бэкапами базы рядом с проектом (в идеале ещё и выкачивать)
- на сайте нужна отдельная категория алкоголя (ноябрь 2026)
- уходят со страницы на mos.ru на свой сайт: там нет модерации, нет обновлений и нельзя продвигать алкогольную продукцию
- для тестового показа боевой Go-версии выбрал бесплатный стенд на Render (приватный репозиторий Drolkill/navolne-site)
- решения по сайту (22.11.2026): списки товаров подгружаются бесшовно при прокрутке, без кнопок «ещё»; показывать только цену, указанную у товара (без пересчёта на полный вес); повторные покупки не отслеживать (без «Вы уже брали»/«Вы смотрели»); нужен раздел «Для бизнеса» — аренда помещений на рынках для мероприятий и контакты для заказа у них как у поставщиков свежей продукции
- 22.11.2026: архитектуру витрины оставляют гибридной (сервер отдаёт страницы, переходы без перезагрузки), не переписывают в SPA; цель — ощущение веб-приложения (вкладки с памятью, мгновенный «Назад», установка на телефон, заглушки загрузки, нативные жесты)
- 22.11.2026: для значков сайта выбран набор Hugeicons (вариант E); переходит к шагам полноценного запуска — первым делом нужно получать всю базу товаров из 1С и видеть остатки с регулярным обновлением
- учёт у них в 1С: Комплексная автоматизация; от обмена с 1С нужно только регулярное обновление товаров и остатков на сайте (без истории остатков)
